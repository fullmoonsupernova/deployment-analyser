Production Deployment Risk Analyzer

A deployment can pass all unit tests, integration tests, and staging, yet still trigger a critical production incident. This system deterministically scans changes across code, infrastructure, dependencies, migrations, and traffic patterns, then evaluates production failure modes and generates a safer rollout strategy.

This analysis compares the deployment candidate against the previous repository revision. The previous revision is used as the analysis baseline and is not assumed to be identical to the currently deployed production version.
